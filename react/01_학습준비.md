#### Git LFS 설치

- 기본적으로 git은 여러 개의 작은 소스코드 파일들을 위한 버전 컨트롤 시스템(VCS)이다.
- 따라서 Github의 경우 50Mb부터 Warning이 표시되고, 100Mb부터는 push시 Error가 발생한다.
- 그런데도 때에 따라서 반드시 대용량 파일을 git repo에 포함해야 하는 상황이 존재할 수 있다.
- 이럴 때 사용할 수 있는 해결책이 `Git LFS(Large File Storage)`이다.

- LFS 설치하기

```javascript
$ git lfs install
```

- 그다음 lfs로 관리할 파일을 track 한다.
- 기본적으로 해당 파일을 git add 하기 전에, git lfs track을 해주어야 한다.

```javascript
git lfs track <file path>
```

- 예를 들어 psd 파일을 track 한다면

```javascript
git lfs track "*.psd"
```

- 그러면 해당 파일의 내용이 원래의 contents가 아니라, lfs pointer로 바뀌는 것을 알 수 있다.
- 또한, lfs로 트래킹하는 파일에 대한 정보는 .gitattributes을 통해서 관리가 되어 이 변경사항을 꼭 add 해주어야 한다.
- 나머지는 일반적인 git push와 동일하다.

```javascript
$ git add .gitattributes
$ git commit -m "update gitattributes for lfs"
$ git push
```

#### EditorConfig 설치

- 개발자들이 일정한 컨벤션을 유지할 수 있게 도와주는 도구
- 많은 개발자가 다양한 Editor나 IDE와 관계없이 일정한 코드 스타일을 유지하기 위해 도와주는 설정 파일이다.
- 파일 형태로 유지되며 읽기 쉽고 스타일에 대한 형상관리가 가능한 장점이 있다.
- 확장 프로그램으로 EditorConfig을 설치하고, 프로젝트 폴더에서 우클릭 `generate .editorconfig`을 클릭하면 .editorconfig 파일이 생성된다.

#### htmlhint 설치

- HTML을 위한 정적 코드 분석 도구이다.
- HTML 파일에서 오류를 표시해준다.
- 예를 들어, 중복된 id가 있는 경우 등의 문법오류

- htmlhint 설치

```javascript
$ npm install —save-dev htmlhint
```

- `.htmlhintrc` 파일 만들기

```javascript
// .htmlhintrc
{
  "tagname-lowercase": true,
  "attr-lowercase": true,
  "attr-value-double-quotes": true,
  "doctype-first": true,
  "tag-pair": true,
  "spec-char-escape": true,
  "id-unique": true,
  "src-not-empty": true,
  "attr-no-duplication": true,
  "title-require": true
}
```

- .htmlhintrc 파일을 json 파일로 변경하기
- vscode 왼쪽 아래에 톱니바퀴, setting에서 htmlhint 검색 후, 첫 번째 edit in setting.json에 아래의 내용을 추가

```javascript
"files.associations": {
  "*.js": "javascriptreact",
  "*rc": "json",
  ".browerslistrc": "plaintext",
  ".zshrc": "python“
}
```

#### Git 별칭 등록

- 손쉬운 Git 명령어 실행을 위해 원하는 별칭을 등록한다.
- Git 글로벌 파일을 열어 보다 편하게 설정할 수 있다.

```javascript
$ code ~/.gitconfig
```

```javascript
// .gitconfig
[user]
  name  = 사용자 이름
  email = 사용자 이메일
[core]
  precomposeunicode = true
  quotepath         = false
  editor            = code --wait
[filter "lfs"]
  clean    = git-lfs clean -- %f
  smudge   = git-lfs smudge -- %f
  process  = git-lfs filter-process
  required = true
[init]
	defaultBranch = main

[alias]
  l = log --all --graph --oneline --decorate
	unstage = reset HEAD --
  last = log -1 HEAD
```
