#### 자바스크립트 실행환경
- `웹 브라우저` = `ECMAScript + 클라이언트 사이드 Web API`(DOM 등)
- `node.js` = `ECMAScript + Host API(파일 시스템 등)`
- Node.js는 외부에서 자바스크립트 개발환경을 제공하는 것이 주 목적이기 때문에 DOM을 지원하지 않는다. 브라우저 외부 환경에서는 HTML 요소를 파싱해서 객체화한 DOM을 직접 다룰 필요가 없기 때문이다.
- 반대로, Node.js는 파일을 CRUD 할 수 있는 파일시스템을 기본 제공하지만, 브라우저는 이를 지원하지 않는다.

#### Node.js와 npm
- `Node.js` : 크롬 v8 자바스크립트 엔진으로 빌드된 자바스크립트 런타임 환경(runtime environment)이다. 간단히 말해 브라우저에서만 동작하던 자바스크립트를 브라우저 이외의 환경에서 동작시킬 수 있는 자바스크립트 실행환경이다.
- `npm(node package manager)` : 자바스크립트 패키지 매니저이다. Node.js에서 사용할 수 있는 모듈들을 패키지화해서 모아둔 저장소 역할과 패키지 설치 및 관리를 위한 CLI를 제공한다. 

#### 픽셀(Pixel)
- `해상도` : 종이나 스크린 등에 표현된 그림이나 글씨 따위가 표현된 섬세함의 정도
- `픽셀(pixel)` : 컴퓨터에서 표현되는 이미지의 최소단위, `pix + element`의 합성어
- 모든 컴퓨터의 이미지는 픽셀로 이루어져 있으며, 이 픽셀이 가지는 컬러의 깊이로 해상도가 결정된다.
- 픽셀은 해상도에 의해 결정되는 단위이기 때문에 해상도에 따라서 픽셀은 상대적이다.
- 픽셀의 수, 밀도가 크면 클수록 선명도가 높아지나, 픽셀이란 미리 물리적으로 정해진 크기가 아니고 설정된 화면 해상도에 따라 정해지는 상대적인 크기다.
